# Deployment

## Purpose

This section captures the current consumption and packaging guidance for Extend0 major `1`.

## Audience

This page is for consumers, maintainers, and release-oriented contributors who need practical guidance on how Extend0 should be consumed today.

## Child Document Map

- [Packaging and Consumption](Deployment/Packaging.md): current preferred consumption path and packaging caveats

## Current Deployment Stance

Extend0 major `1` is still consolidating its public platform story. That means deployment guidance should optimize for reliability and clarity over aggressive packaging claims.

For the current phase:

- direct project references are the safest path for active development
- releases and NuGet remain useful distribution channels
- documentation should be explicit about generator and public API caveats instead of assuming perfect packaging alignment
