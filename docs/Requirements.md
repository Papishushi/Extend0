# Requirements

## Purpose

This section states what Extend0 major `1` is trying to become, what should be prioritized now, and how the main systems are expected to stay coherent.

## Audience

This page is for:

- maintainers making scope and sequencing decisions
- contributors who need to understand what is core versus deferred
- readers who want the platform story without dropping into implementation detail yet

## Child Document Map

- [Major 1 Direction](Requirements/Major-1-Direction.md): the current north star and next-milestone priority
- [System Boundaries](Requirements/System-Boundaries.md): what belongs to `Lifecycle`, `MetaDB`, ontology, and code generation

## Current Requirement Baseline

The current requirement baseline for Extend0 major `1` is platform-core consolidation:

- align `README`, docs, ADRs, and ontology
- harden `Lifecycle` and `MetaDB` before expanding the ecosystem surface
- use ontology as an architectural mirror instead of as speculative future-fiction
- keep `UByteC` integration as a prepared direction, not the immediate implementation center
